---
title: "Key states"
description: "What each state of a key ring and key means."
---

| State | Meaning | Can sign |
|---|---|---|
| **Provisioning** | Strongpoint is creating the key. Key rings skip this state. | No |
| **Ready** | In use. | Yes |
| **Disabled** | The key ring's account is archived. It signs again once you unarchive the account. | No |
| **Provisioning failed** | The key could not be created. | No |

A ready key in a disabled key ring shows **Signing paused**.

On a key's **Versions** tab, **Current** marks the version that signs. If the key isn't ready, the label adds its state, for example **Current · Disabled**.

Each version also shows what it can do: **Signs & verifies**, **Verify only** or **Unusable**.
