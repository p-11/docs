## Algorithms

| Algorithm | Type | Standard | Notes |
|---|---|---|---|
| **ML-DSA-65** | Post-quantum | FIPS 204, category 3 | Recommended for general use |
| **ML-DSA-87** | Post-quantum | FIPS 204, category 5 | Strongest option |
| **ECDSA-P256** | Classical | FIPS 186-5 | Works with most existing verifiers |
| **ECDSA-secp256k1** | Classical | secp256k1 | For blockchains and verifiers that use secp256k1 |

Classical algorithms are not quantum-safe. The **Algorithms** column on **Signing keys** shows which algorithms each key ring uses.

## Provider

Strongpoint holds your keys with **PEAK**, a threshold enclave. Each key is split into shares held on your members' iPhones, so no one holds a key whole. PEAK supports every algorithm above.
