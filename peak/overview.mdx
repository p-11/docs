Strongpoint uses PEAK to protect your organization's keys. Your organization has a single root key, and every wallet and address you use on Strongpoint is derived from it. No one person ever holds the whole root key.

<Info>Your root key protects all the funds you hold on Strongpoint. PEAK stores it so that no single person, iPhone or server can use it alone.</Info>

## Where your root key is stored

Your root key is split into shares, and the shares are stored in two places:

| | Root key holders | Backup iPhones |
|---|---|---|
| **Who** | 3 to 30 members you choose | 3 to 30 separate iPhones, one per backup holder |
| **On** | Each holder's everyday iPhone | A dedicated iPhone, powered off and kept somewhere safe |
| **Used for** | Creating accounts and their keys, and creating the backup key | Recovering the root key if too many holders lose their shares |

Keeping the root key in both places means you can always get it back, and no single lost or stolen iPhone is enough to use it. Any member with an enrolled iPhone can hold a share, whatever their role.

## Setting up your organization with PEAK

<Warning>Until PEAK setup is complete, you can't create accounts or deposit funds.</Warning>

An **Org setup** card in the sidebar guides you through PEAK setup and shows who each step is waiting on. Once the root key and backup key are both in place, **Portfolio** appears and you can [create your first account](/portfolio/manage-accounts).

| Step | What happens | Who |
|---|---|---|
| **Invite members** | Invite at least 2 more people. | Owner or Admin |
| **Device enrollment** | At least 3 members enroll their iPhones. | New members, then approvers |
| **Set up root key** | Choose the holders. Every holder approves, then accepts their share. | Owner, then holders |
| **Enroll backup iPhones** | Each backup holder enrolls a separate backup iPhone. | Backup holders |
| **Set up backup key** | Root key holders and every backup iPhone approve, then the backup iPhones accept their shares. | Owner, then holders |

## Who can do what

- **Owners** set up the root key and the backup key, test them, and start a recovery.
- **Owners and Admins** see the **Root key** tab on **Signing keys**, and request device enrollments for holders.
- **Holders**, whatever their role, approve PEAK requests and accept their shares on their iPhone.
